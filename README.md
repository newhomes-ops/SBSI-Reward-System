# SBSI Reward System

Program concept, submission forms and tracking tool for the SBSI Reward System.

| File | Description |
|---|---|
| `index.html` | Program concept presentation (17 slides). Open in a browser; use ◀ ▶ or arrow keys. |
| `forms/submission-form.html` | Online submission form. Prepares a summary for the submitter to copy and email. |
| `forms/sbsi-reward-submission-form_2026-09-30.xlsx` | Excel version of the submission form. |
| `docs/sbsi-reward-system-memo_MTO-MEMO-001A_2026-09-29.docx` | Program concept memo. |
| `docs/performance-qualification-matrix_2026-09-29.xlsx` | Performance Qualification Matrix: qualification, recognition and corrective action logs, scorecard and dashboard. |

Figures shown in the presentation and workbook are illustrative sample data (fictional employees).
